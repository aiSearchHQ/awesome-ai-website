# Image To Prompts

Image To Prompts turns an uploaded image into an editable text prompt and also includes live AI image and pixel-art generation. The workflow helps users study how a visual can be described and then reuse or refine that description.

It may be useful for prompt learning, recreating a visual direction, pixel-art experiments, and moving from a reference image to a new generated concept.
