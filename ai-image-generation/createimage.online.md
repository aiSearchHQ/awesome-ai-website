# CreateImage Online

CreateImage Online is a browser-based AI creative workspace for generating images from text, editing reference images, and turning finished still images into short AI videos. It brings several common visual workflows into one interface, so users can move from an idea to a downloadable result without installing desktop software.

## Main Features

- **Text-to-image generation:** Use Seedream to turn detailed written prompts into original pictures.
- **Reference image editing:** Upload a JPG, PNG, or WebP image and use natural-language instructions with Nano Banana to change it while preserving important subjects and context.
- **Image-to-video creation:** Use Seedance to add motion to a finished still image.
- **Creative examples:** Browse portraits, product visuals, illustrations, and cinematic scenes for ideas and prompt inspiration.
- **Iterative workflow:** Compare results, refine the prompt, generate another version, and download the preferred output.

## Typical Use Cases

CreateImage Online can be useful for:

- Social media artwork and short-form content
- Blog illustrations and website graphics
- Product concepts and marketing visuals
- Character, portrait, and scene exploration
- Turning a still image into a short animated clip
- Rapid visual experiments before moving into a larger design workflow

## How It Works

1. Describe the image you want, or upload a reference picture.
2. Choose an image generation, image editing, or animation model.
3. Generate the result and review the output.
4. Refine the instructions when needed, then download the version you want to use.
