# VideoInPrompt

VideoInPrompt converts videos and images into reusable prompts, then supports generating images or videos from text and visual references. It connects prompt extraction with a new content-generation workflow.

It may be useful for studying visual style, rebuilding a scene direction, learning prompt structure, and moving from an existing reference to a new generative result.
