# ImageVids AI

ImageVids AI turns static images into generated videos using multiple models and prompt-based motion control. The reference image establishes the visual starting point while the prompt guides how the scene should move.

It may be useful for animating artwork, product images, portraits, social graphics, and other still assets without building motion manually.
